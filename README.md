# KD-ToolsClub Static Site

Plain HTML/CSS/JS only.

## Structure
- index.html
- tools.html
- kits.html
- about.html
- contact.html
- privacy.html
- robots.txt
- sitemap.xml
- assets/css/style.css
- assets/js/app.js

Before launch:
1. Replace YOUR-DOMAIN.com in robots.txt and sitemap.xml.
2. Replace YOUR-DONATION-LINK-HERE in assets/js/app.js.
3. Replace YOUR_FORM_ID in contact.html with your Formspree form ID, or connect your own backend.
